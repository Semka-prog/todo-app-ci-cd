# Отчет по практической работе: Git, GitHub Flow и CI/CD

## 1. Цель работы

Целью работы было доработать консольное Todo-приложение, настроить автоматическую сборку и тестирование, выполнить публикацию исполняемого JAR в GitHub Releases и пакета в GitHub Packages.

## 2. Технологии

- Java 17
- Gradle Wrapper 8.10.2
- JUnit Jupiter 5
- Shadow plugin
- GitHub Actions
- GitHub Releases
- GitHub Packages

## 3. Реализация приложения

Приложение содержит модель задачи `Task`, сервис `TaskService` и консольный интерфейс `TodoApp`.

Реализованы операции:

- добавление задачи;
- установка состояния выполнения;
- очистка списка;
- поиск задач без учета регистра;
- просмотр списка;
- интерактивные команды.

## 4. Тестирование

В JUnit 5 написаны тесты для добавления задач, проверки пустых названий, установки выполненного состояния, очистки списка, поиска и защиты внутреннего состояния списка.

Команда проверки:

```powershell
.\gradlew.bat clean build
```

## 5. Git и ветвление

Используется GitHub Flow:

1. создается feature-ветка;
2. изменения коммитятся;
3. создается Pull Request в `main`;
4. CI проверяет сборку и тесты;
5. после одобрения изменения вливаются в `main`.

## 6. CI/CD

Workflow `ci.yml` запускается при push и pull request в `main`, устанавливает JDK 17 и выполняет `./gradlew clean build`.

Workflow `release.yml` запускается для тегов `v*`. Сначала выполняются тесты и сборка, затем публикуются GitHub Packages и GitHub Release. Падение тестов предотвращает запуск последующих публикационных шагов.

Workflow `nightly.yml` запускается по cron-расписанию ежедневно в 03:00 UTC и выполняет только сборку с тестами.

## 7. Сборка артефакта

Shadow plugin собирает исполняемый JAR:

```text
build/libs/todo-app.jar
```

## 8. Публикация пакета

Для GitHub Packages используются координаты:

```text
org.example:todo-app:<tag-version>
```

Публикация выполняется с `GITHUB_ACTOR` и `GITHUB_TOKEN`.

## 9. Вывод

В результате получено консольное Java-приложение с тестами, автоматизированной сборкой, nightly-проверкой, системой релизов и публикацией артефакта.
